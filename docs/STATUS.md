# Project status and scope

`flyfishHep` v0.4.0 is an **unreleased alpha candidate** research-workflow toolkit distributed under MIT. It is an original standalone project; using or installing it does not modify an existing Hermes configuration or profile.

## Implemented and exercised

- A stage-aware and HEP-specific research protocol, module guides, generic contract, templates and an optional Hermes skill adapter.
- Python 3.9+ standard-library CLI for drafts, strict contract validation, content-addressed snapshots, explicit local execution, retained receipts, recomputed numerical criteria, audit, report and a deterministic next-step navigator.
- Read-only audited run history and provenance-aware same-freeze criterion comparison; damaged and non-comparable evidence remains explicit.
- Two elementary public-source demonstrations under `examples/`, exercised through the installed CLI.

- A standalone versioned research handoff (`research.json`) for analytic/literature work as well as numerical projects; complete export/host-observation/update flow, stale-base refusal and confirmation-to-exploration transitions.

- Optional local evidence bindings with fresh file/run currency findings and scoped affected-observation IDs; descriptive locators are not semantic citation validation.
- Short question/plan/observe/suspend actions using the existing handoff validator.
- Explicitly granted, bounded host operations with durable results and non-replay recovery for uncertain attempts; no model controller or sandbox.
- A model-independent maintenance report script; it does not review or merge contributions.

## Not established / excluded

No evidence here establishes novelty, general problem-solving competence, scientific validation of a new result, effectiveness across fields/users, a safe sandbox, benchmark improvement or production-grade security. CI and local checks address software behavior only; users remain responsible for scientific review, code trust and applicable institutional obligations. The examples are pedagogical, not held-out evaluation cases.
